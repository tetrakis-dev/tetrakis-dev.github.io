Support

Every Tetrakis tool comes with email support. You get an answer from the developer, usually within two working days.

Send your request to

contact@tetrakis.dev

What to include

  1. The name and version of the Tetrakis tool.
  2. Your Unity version and render pipeline (Built-in, URP or HDRP).
  3. The target platform (Editor, Windows, Linux, …).
  4. What you expected and what happened, with the error message or console log if there is one.
  5. If the problem comes from a specific file, say so. We will agree on a confidential way to share it before you send anything.

Bug reports and feature requests

Both are welcome by email. Files that fail to load are especially useful: each one fixed makes the tool more reliable for everyone.

Tetrakis builds tools for Unity developers. Contact: contact@tetrakis.dev
